# Network Reconnaissance Tool

A Python-based network reconnaissance tool that uses **Nmap** to gather information about a target system. The tool provides a simple menu-driven interface for running different types of scans, reviewing open ports and services, and saving the results for later analysis.

I built this project to get more hands-on experience with **Python, networking, Nmap, and security reconnaissance** instead of only learning these concepts theoretically. I intend to use this tool in a bigger project and improve on it if required.

> **Note:** Only use this tool against systems and networks you own or have explicit permission to test.

## What It Does

The tool currently supports:

* Basic Nmap port scanning
* Service and version detection
* Operating system detection
* Default, common, custom, and port-range scans
* Target validation and hostname resolution
* Detection of open TCP ports
* Service and version information from Nmap
* Security findings for selected commonly exposed services
* Severity levels for security findings
* Human-readable TXT reports
* Structured JSON reports
* Scan history

## How It Works

When the program starts, you can either start a new scan or view previous scan results.

For a new scan, the tool asks for:

1. The target IP address or hostname
2. The type of Nmap scan
3. The ports to scan

The selected options are then used to build and execute the Nmap command through Python.

The tool parses the Nmap output and extracts information such as:

* Target
* IP address
* Open TCP ports
* Service names
* Service versions
* Operating system information

The results are then displayed in the terminal and saved to the `reports` directory.

## Scan Modes

### Basic Scan

Runs a standard Nmap scan to identify open ports and services.

### Service/Version Scan

Uses Nmap's `-sV` option to identify services and, where available, their versions.

### OS Detection

Uses Nmap's `-O` option along with service detection to gather operating system information.

OS detection may require elevated privileges depending on the system and Nmap configuration.

## Port Scan Options

The tool provides several ways to select ports:

* **Default ports** — uses Nmap's default scan
* **Common ports** — scans the top 20 ports
* **Custom port** — scans a single port
* **Port range** — scans a specified range such as `1-100`

The program validates custom ports and port ranges before starting the scan.

## Security Findings

After identifying open ports, the tool checks them against a small set of predefined services.

Examples include:

| Port | Service | Severity |
| ---- | ------- | -------- |
| 21   | FTP     | MEDIUM   |
| 22   | SSH     | LOW      |
| 23   | Telnet  | HIGH     |
| 443  | HTTPS   | LOW      |
| 445  | SMB     | MEDIUM   |

These findings are **basic security guidance generated by the Python program**. They are not vulnerability detections performed by Nmap.

For example, detecting port 445 does not automatically mean the system is vulnerable. The tool simply identifies the service and provides a reminder to review its exposure and configuration.

## Reports

Each completed scan generates two report files:

### TXT Report

A human-readable report containing the scan summary, open ports, service information, and security findings.

### JSON Report

A structured version of the scan results that can be used for further processing or future automation.

Example structure:

```json
{
    "target": "localhost",
    "ip_address": "127.0.0.1",
    "scan_mode": "OS detection",
    "port_selection": "Port 9999",
    "operating_system": "Windows",
    "open_port_count": 1,
    "open_ports": [],
    "security_findings": []
}
```

Reports are saved in:

```text
reports/
```

## Scan History

The tool also keeps a record of previous scans in:

```text
scan_history.json
```

The history stores information such as the target, scan mode, port selection, operating system, date, number of open ports, and security findings.

The **View scan history** option allows previous scan results to be reviewed directly from the terminal.
